# Freebuff Self-Hosted Lite

Versão enxuta para subir facilmente no GitHub. Inclui uma interface web simples e um backend compatível com os endpoints principais do Freebuff.

## Rodar

1. Instale Bun.
2. Copie `.env.example` para `.env`.
3. Coloque sua chave do provedor em `PROVIDER_API_KEY`.
4. Ajuste `MODELS` se quiser vários modelos.
5. Execute `bun run start`.
6. Abra `http://localhost:8787`.

Este backend não impõe quota nem anúncios. Os limites/custos do provedor de IA continuam valendo.
